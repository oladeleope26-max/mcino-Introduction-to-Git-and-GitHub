Simple Interest Calculator
A simple interest calculator to compute interest earned or paid on a principal amount.
Description
This calculator computes simple interest based on the principal amount, annual interest rate, and time period. It is useful for personal finance, loans, and savings calculations Formula
Simple Interest (SI) = (P × R × T) / 100
Total Amount = P + SI

Where:
- P = Principal amount
- R = Annual interest rate (in %)
- T = Time period (in years)
How to Use
1. Enter Principal amount
2. Enter Rate of interest
3. Enter Time in years
4. Calculate: (P * R * T) / 100

 Example
Principal = 10000, Rate = 5%, Time = 2 years
SI = (10000 * 5 * 2) / 100 = 1000
Total = 11000

 Code Example (Python)
interest = (principal * rate * time) / 100
